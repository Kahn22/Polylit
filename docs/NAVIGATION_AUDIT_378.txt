POLYLIT NAVIGATION AUDIT — CHECKPOINT 378
Date: 2026-10-03
Baseline: checkpoint 377, twelve works (nine French, three Spanish).
Scope: generated public pages, application routes, both reading modes, shelf
controls, vocabulary/expression dialogs, prepared reviews, recovery links.

FIXED
1. Direct /fr/library/index.html and /es/library/index.html visits displayed
   inert cards: entry and application routing now share the same path parser.
2. Continue learning reset the section to zero. Learning positions now persist
   per language/work; position-bearing hashes support reload and history.
   Book View also records its part in the URL for history restoration.
3. Text reviews started from the library always returned to Learning View.
   Completed works could fall through to login. Reviews now return to their
   origin; completed shelves remain completed.
4. Previous section, library return, Book View, Choose language, and Mark
   completed bypassed due-section review. App controls now offer review,
   skip-to-the-requested-destination, and reread before leaving the section.
   Shelf changes are deferred until the learner completes or skips review.
5. Invalid/unavailable work routes fell through to login. Signed-in visitors
   now recover to the selected library without encountering unseen content.
6. Old root hash bookmarks were ignored by the standalone landing page.
   Recognized legacy links now transfer to the selected language document,
   preserving the work hash and repository prefix.
7. Restored documents could retain a signed-out preview screen. The landing
   script checks session state on entry/pageshow; restored app pages reload
   browser-local shelf/progress state.
8. Reader pagination could leave the viewport at the bottom of the next page.
   New reading sections, Book View parts, and unanswered questions start at
   the top. Answer feedback keeps focus on Continue.
9. Dialog keyboard focus could escape into background navigation. Tab cycles
   within the sheet; closing returns focus to its trigger. Escape closes menus.
10. Book rendering lacked the stale-render guard used by Learning View. Both
    views now reject superseded content renders.
